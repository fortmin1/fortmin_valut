
| 概念                                  | 核心作用      | 类比     |
| ----------------------------------- | --------- | ------ |
| OLTP(Online Transaction Processing) | 支撑业务交易    | 营业员记账  |
| HTAP                                | 边交易边分析    | 实时判断风险 |
| OLAP                                | 历史统计分析    | 老板看报表  |
| Data Lake                           | 存所有原始数据   | 仓库堆原材料 |
| Lakehouse                           | 数据湖+数据库能力 | 智能仓库   |
| Raw Data Lake                       | 保存最初数据    | 原料仓    |
