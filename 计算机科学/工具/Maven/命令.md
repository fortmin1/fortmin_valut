> 格式：`mvn [命令] [参数]`
> 
> 常用参数：

- `-U` / `--update-snapshots`：强制更新快照依赖，清除`.lastUpdated`缓存（你之前报错高频用到）
- `-Dxxx=yyy`：设置 Java 系统属性
- `-Pxxx`：激活 profile，多个用逗号分隔 `-Pa,b`
- `-pl module1,module2`：多模块，只构建指定子模块
- `-am`：同时构建该模块依赖的其他模块
- `-X`：输出 debug 详细日志，排查问题
- `-q`：安静模式，只输出错误
- `-DskipTests`：跳过单元测试（不执行测试，依然编译测试代码）
- `-Dmaven.test.skip=true`：跳过编译 + 执行测试代码

## 一、生命周期核心命令（Maven 三大生命周期：clean、default、site）

### clean 生命周期（清理）

```
mvn clean          # 删除target目录，清理编译输出产物
```

### default 主生命周期（编译、测试、打包、安装、部署）

按顺序执行，执行后面阶段会自动执行前面所有阶段：
```
mvn validate       # 校验项目结构、配置是否合法
mvn compile        # 编译主代码 → target/classes
mvn test           # 编译并执行单元测试
mvn package        # 打包：jar/war，输出到target
mvn install        # 打包后安装到本机本地仓库(.m2/repository)，本机其他项目可以引用
mvn deploy         # install之后，上传构件到远程nexus私服（需要distributionManagement配置+servers账号）
```

> 高频组合命令

```
mvn clean compile
mvn clean package -DskipTests
mvn clean install -U -DskipTests
mvn clean deploy -DskipTests
```

### site 生命周期（生成项目站点文档，很少用）
```
mvn site       # 生成项目html报告文档
mvn site:deploy # 把站点文档部署到服务器
```

## 二、插件命令（plugin: 目标，最常用工具命令）

### help 帮助插件（排查配置神器，你前面用到）

```
mvn help:effective-pom      # 输出合并之后完整pom（super‑pom+父pom+当前pom，看最终生效repositories、依赖）
mvn help:effective-settings # 输出合并后的settings.xml
mvn help:describe -Dplugin=dependency # 查看某个插件信息
mvn help:all-profiles       # 列出所有profile，显示哪些激活
```

### dependency 依赖插件（日常排查依赖问题）

```
mvn dependency:list                # 列出本项目全部依赖
mvn dependency:tree                # 打印完整依赖树，看传递依赖、版本冲突
mvn dependency:resolve             # 解析所有依赖，下载到本地仓库
mvn dependency:get -DgroupId=xxx -DartifactId=xxx -Dversion=xxx [-Dtype=pom] # 手动下载指定构件到本地仓库
mvn dependency:copy-dependencies   # 把所有依赖jar复制到target/dependency目录
mvn dependency:analyze             # 分析依赖：找出未使用、缺失的依赖
mvn dependency:purge-local-repository # 清理本项目相关的本地缓存，重新下载
```

### 其他高频插件
```
mvn versions:display-dependency-updates # 检查依赖有没有新版本
mvn versions:set -DnewVersion=2.0.0    # 批量修改项目版本号（多模块）

mvn spring-boot:run   # springboot项目直接运行（springboot插件）
mvn spring-boot:repackage # springboot打包可执行jar

mvn archetype:generate # 使用archetype模板快速新建maven项目
```

## 三、多模块项目常用参数

```
# 只构建子模块dataSync‑jdbc，同时构建它依赖的模块(-am)
mvn clean install -pl dataSync-jdbc -am -DskipTests

# 排除某个模块
mvn clean install -pl '!module-b'
```

## 四、常用完整示例（工作高频）

```
# 清理+编译，强制刷新快照
mvn clean compile -U

# 打包跳过测试
mvn clean package -DskipTests

# 安装到本地仓库，强制更新快照
mvn clean install -U -DskipTests

# 部署到nexus私服
mvn clean deploy -DskipTests

# 打印依赖树，排查jar冲突
mvn dependency:tree

# 看最终合并pom，排查仓库、parent问题
mvn help:effective-pom

# debug模式执行，详细日志排查http仓库、下载报错
mvn clean compile -X -U
```

## 五、生命周期阶段简单理解

> mvn 执行一个阶段，会顺序执行该生命周期**前面所有阶段**。
> 
> 例：`mvn install` 会依次执行：`validate → compile → test → package → install`。

## 六、易混淆参数区分

1. `-DskipTests`：**不跑测试用例，但是编译测试代码**
2. `-Dmaven.test.skip=true`：**不编译、也不运行测试代码**

## 七、常见报错对应命令

1. parent pom 下载失败、`.lastUpdated`缓存：加 `-U`
2. 不知道最终生效哪些仓库：`mvn help:effective-pom`
3. jar 包版本冲突：`mvn dependency:tree`
4. 想看 maven 完整网络请求日志：`‑X`
