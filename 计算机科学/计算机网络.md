# URI
URI(Uniform Resource Identifier)统一资源标识符。
作用：唯一标识互联网上资源的字符串，不作定位，只做唯一标识。
分为两类：
- URL：既标识资源也定位资源。
- URN：仅唯一命名资源。

| 类型                 | 示例                                 | 说明                   |
| ------------------ | ---------------------------------- | -------------------- |
| URL（也是 URI）        | `https://www.baidu.com/index.html` | 有协议、域名、路径，可直接访问      |
| URN（只是 URI，不是 URL） | `urn:isbn:9787111636663`           | 图书 ISBN 编号，仅标识，无访问地址 |
| 纯路径 URI（非完整 URL）   | `/api/user/list`                   | 只有资源路径，缺少协议域名，不能独立访问 |
## URL标准格式（RFC 3986）
```
scheme://username:passwd@host:port/path?query#fragment
```
