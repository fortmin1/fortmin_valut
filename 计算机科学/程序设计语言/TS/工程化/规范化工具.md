# husky
**husky 用来简化 Git Hook 配置**

Git 原生自带钩子（pre-commit、commit-msg、pre-push…），可以在 git 操作前后执行脚本。

原生配置非常麻烦，husky 封装 API，一键启用钩子。

> 常见场景：
> 
> `pre-commit`：执行 eslint/prettier，代码有错误阻止提交
> 
> `commit-msg`：校验 commit 信息规范（如约定式提交 feat/fix）
> 
> `pre-push`：push 前执行单元测试
# editorconfig
一套通用编辑器配置标准，**跨编辑器统一代码基础风格**。

解决痛点：团队有人用 VSCode、WebStorm、Sublime，缩进、换行、编码不一致，代码到处出现空格冲突。

> 原理：编辑器安装 EditorConfig 插件后，打开文件自动读取项目内 `.editorconfig`，覆盖编辑器默认设置。
