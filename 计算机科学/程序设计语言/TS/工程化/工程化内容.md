一句话定义：**前端工程化就是用工程手段，解决前端开发、构建、部署、协作、维护中的各类重复、混乱问题，把手工操作标准化、自动化。**

整体分为 6 大模块：**规范体系、构建工具、模块化 & 工程架构、自动化流程、质量保障、部署运维**

## 一、代码规范化（团队协作基础）

解决：多人代码风格不统一、提交杂乱、注释混乱

1. **编辑器规范**
    
    - `.editorconfig`：统一缩进、换行符、文件编码
    
2. **代码格式规范**
    
    - Prettier：自动格式化代码
    - ESLint / TSLint：JS/TS 语法、代码质量检查
    - Stylelint：CSS/SCSS 样式校验
    
3. **Git 提交规范**
    
    - Husky：管理 Git Hook
    - lint-staged：只校验暂存区代码
    - commitlint + conventional commits：规范 commit 信息（feat/fix/docs…）
    

> 就是你刚才问的 `.editorconfig`、`.husky` 都属于这一块。

## 二、模块化 & 资源管理

解决：全局变量污染、文件依赖混乱、浏览器原生不支持模块

1. 模块化方案
    
    - CommonJS（Node）、ESModule(ESM)、AMD、UMD
    
2. 资源处理
    
    - JS、TS、Vue/React 组件、CSS、图片、字体、静态资源导入
    
3. 依赖管理
    
    - npm/yarn/pnpm 包管理
    - `package.json`、lock 文件、依赖版本控制
    - monorepo 多包管理（pnpm workspace、turbo、lerna）
    

## 三、构建与编译（打包工具核心）

解决：浏览器不能直接识别 TS、Vue、JSX、Sass；代码臃肿、需要压缩

### 核心能力：

1. **编译转译**
    
    - Babel：ES6+ 转 ES5、TS 降级
    - ts-loader /esbuild：TypeScript 编译
    
2. **打包、资源拼接**
3. **产物优化**
    - sourcemap
    - Tree-Shaking 消除无用代码
    - 代码分割 splitChunks、懒加载
    - 资源压缩（JS/CSS/ 图片压缩）
    - 静态资源哈希（防止缓存）
    
4. **开发环境能力**
    
    - 本地开发服务器、热更新 HMR、代理 proxy
    

### 主流工具：

- Webpack（传统主流）
- Vite（现代，基于 esbuild 预构建）
- Rollup（类库打包）
- esbuild /swc（高性能编译工具）

## 四、自动化流程（自动化脚本）

把重复命令写成脚本，解放双手

1. 任务调度工具：npm scripts、Gulp
2. 能力：
    
    - 清理旧打包产物
    - 自动生成路由、自动生成接口请求代码
    - 多环境变量区分（开发 / 测试 / 生产）`.env`
    
3. 环境区分：开发环境、测试环境、预发、生产环境

## 五、质量保障体系

保障线上代码稳定，提前发现问题

1. **单元测试**：Jest、Vitest
2. **E2E 端到端测试**：Cypress、Playwright
3. **可视化测试、性能测试**
4. **CI 持续集成**（GitLab CI / GitHub Actions / Jenkins）
    
    - 代码合并自动执行：lint、测试、构建
    

> 本地 husky 是前置防线，CI 是远端兜底防线

## 六、部署、运维与监控

1. 静态资源部署
    
    - 打包产物上传 CDN、静态服务器
    
2. 工程能力：
    
    - 环境变量注入、路由基础路径配置
    - 资源预加载、Gzip/Brotli 压缩
    
3. **线上监控**
    
    - 错误监控：Sentry
    - 性能监控、埋点上报
    
4. 版本管理：灰度发布、静态资源版本回滚

# 七、扩展：现代前端工程化额外内容

1. **类型系统**：TypeScript，提升代码健壮性
2. **组件工程化**
    
    - 组件库开发、文档站点（Storybook、Vitepress）
    
3. **跨端工程化**
    
    - Taro、uni-app、React Native 工程体系
    
4. **低代码平台工程化**
5. **微前端**：qiankun、wujie 多应用工程架构

# 极简思维导图（背诵版，面试直接用）

✅ 代码规范（EditorConfig、ESLint、Prettier、Husky、commitlint）

✅ 模块化与依赖管理（pnpm、ESM、Monorepo）

✅ 构建编译（Vite/Webpack、Babel、资源处理、产物优化）

✅ 自动化脚本 & 多环境配置

✅ 部署发布 & 线上监控

## 补充区分容易混淆概念

- `.editorconfig`：**编辑器层面规范**（工程化【代码规范】模块）
- `.husky`：**Git 提交自动化校验**（工程化【质量保障 + 规范落地】模块）
