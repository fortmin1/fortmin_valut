一个完整的软件研发组织其实可以分成四条线：

```
                公司战略
                    │
        ┌───────────┼───────────┐
        │           │           │
    产品体系      技术体系     项目体系
        │           │           │
 Product Manager  Tech Lead   Project Manager
 Product Owner    Architect   Scrum Master
                  Engineering Manager
                  Developer
                  QA
                  SRE
```
# 技术体系
## Developer（研发工程师）
job:
- 编码
- Bug修复
- Code Review
- 单元测试
- 文档
require:
	技术能力
	工程能力
## Senior Developer（高级工程师）
job:
不仅能写代码，还能独立负责模块。
他开始承担：
- 技术方案
- Code Review
- 指导新人
## Tech Lead（技术负责人）
job:
对一个团队的技术结果负责。
Tech Lead负责：
```
技术方案

代码规范

任务拆分

技术难题

Review

上线质量
```
