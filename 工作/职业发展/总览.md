一个完整的软件研发组织其实可以分成四条线：

```
                公司战略
                    │
        ┌───────────┼───────────┐
        │           │           │
    产品体系      技术体系     项目体系
        │           │           │
 Product Manager  Tech Lead   Project Manager
 Product Owner    Architect   Scrum Master
                  Engineering Manager
                  Developer
                  QA
                  SRE
```
